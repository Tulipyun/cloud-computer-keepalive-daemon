## Isolated SOHO timeouts

Two SOHO heartbeat requests reached the 30-second HTTP timeout:

- 2026-07-15 21:03:37 +08:00
- 2026-07-16 15:13:10 +08:00

Both were first failures in their sequence and were followed by a successful heartbeat in about one second. They did not trigger the three-failure threshold or reconnect logic.

Because the SOHO request currently runs in the raw main loop, these timeouts delayed the normally 10-second main `0x74 -> 0x79` cadence to 36 and 39 seconds. The remote session remained healthy. The behavior is documented as a future hardening option rather than changed in this release.

## Conclusion

The test validates that a single, non-rotating pure Go ZTE CAG/SPICE session can maintain the tested cloud desktop for at least four days. There is no evidence that periodic connection rotation, synthetic display traffic or official SDK participation is required for this account and environment.
